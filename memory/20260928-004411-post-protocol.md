The owner wants to publish with Blogger's Post via email, which cannot set a custom permalink, labels or a search description. The agreed protocol, saved in `docs/04-content/04-01-post-protocol.md`, is: title as Thai first with 3–5 English keywords in brackets so Blogger builds an English URL; the post ID as a text-free marker `<div class="mp-id" data-id="NNNN"></div>` at the top of the body, not in the title; and links between posts written as `#NNNN`, which `05-theme.js` turns into links from the blog feed. New posts take the next ID in the register in that document. Check it before writing or publishing any post.
