The owner named https://www.blockdit.com/discover/popular/all as the inspiration for how Mee Prompt should look ("ต้นแบบ ... เป็นแรงบันดาลใจ"). It is a reference for detail and feel, not a template to copy: the owner also wants the current Mee Prompt layout kept (see keep-layout-polish-details).

What Blockdit does that is worth borrowing, as observed on 2026-09-27: content cards with a 16px radius; image first, then a bold title clamped to two or three lines, then one compact meta row (small avatar, 12px author name, like count); no excerpt and no "read more" link because the whole card is the link; pill-shaped filter chips; dense, even spacing; system UI font. Its dark theme, masonry grid and blue accent (#4A69FF) are Blockdit's identity rather than details, so adopt them only if the owner asks.
