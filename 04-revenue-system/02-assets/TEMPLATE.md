# Asset Acceptance Checklist

Before status becomes `ready`:

- [ ] Answers the stated audience problem.
- [ ] Has one clear primary intent.
- [ ] Has a useful next action.
- [ ] Title/slug is stable.
- [ ] Canonical URL plan is known.
- [ ] Internal links are intentional.
- [ ] Monetization placement is defined.
- [ ] No secrets or private data are included.
