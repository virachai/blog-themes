# Stage 20+ Operating Protocol

1. Capture signals with traceable sources or measurements.
2. Convert each signal into one falsifiable hypothesis.
3. Build a brief with user problem, intent, evidence plan, differentiation, outline, links, success metric, observation window, and stop/revise condition.
4. Publish and measure through Layers 02–05.
5. Diagnose as insufficient evidence, positive, mixed, negative, or data-quality issue.
6. Record durable learning and the action it changes.
7. Start the next mission from the strongest unresolved signal, not a fixed publishing quota.

Do not infer causality from correlation alone.
