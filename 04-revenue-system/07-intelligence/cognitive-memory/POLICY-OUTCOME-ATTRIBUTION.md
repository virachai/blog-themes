# Cognitive Policy Outcome Attribution

Stage 50 protects the learning boundary from unverified causal claims.

Observed outcome ≠ automatically policy-caused outcome.

The runtime requires a bound evidence record and an explicit attribution assessment. `UNCERTAIN` and `NOT_ATTRIBUTABLE` remain auditable but cannot enter the learning-eligible path. `DIRECT` and `LIKELY` require rationale plus confounder assessment.

No automatic learning commit occurs here.
