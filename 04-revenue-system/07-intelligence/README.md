# Stage 20+ - Content Intelligence & Learning Loop

Purpose: turn real-world signals and measured outcomes into the next content decisions.

Core loop: Signal → Opportunity → Brief → Asset → Publish → Measure → Diagnose → Decision → Learning → Signal

Every cycle must produce a traceable signal, content hypothesis, measurable target, publishable brief, measurement window, diagnosis, and next action.

## Files
- signals.csv - external or first-party signals.
- briefs.csv - editorial briefs.
- experiments.csv - controlled content experiments.
- learnings.csv - durable lessons.
- TEMPLATE.md - operating protocol.
- value-missions.csv - value-driven editorial missions.
- VALUE-MISSION-TEMPLATE.md - Stage 22 mission schema.
- runs/ - executable mission run artifacts created by Stage 22A.

A brief is ready only when it defines audience/search intent, user problem, evidence requirements, internal-link opportunity, success metric, observation window, and stop/revise condition.
