# 03-03 Page: ติดต่อเรา

Create in Blogger → meefunblog → **Pages** → **New page**.

| Field | Enter |
| --- | --- |
| Title | `ติดต่อเรา` |
| Permalink (Page settings → Permalink → Custom) | `contact` → URL `https://meefunblog.blogspot.com/p/contact.html` |
| Body | Switch the editor to **HTML view**, paste the whole of [02-meefunblog/08-page-contact.html](../../02-meefunblog/08-page-contact.html) |
| Search description (Page settings) | `ช่องทางติดต่อทีม Mee Prompt เรื่อง Prompt และ workflow AI` |
| Comments (Page settings → Options) | Don't allow, hide existing |

## Before publishing

Replace both `[EMAIL]` placeholders with the real contact address. Blogger's own Contact Form widget can be used instead if no public address should be shown.

## Check after publishing

1. Open `https://meefunblog.blogspot.com/p/contact.html` on a phone and a desktop.
2. The menu or footer link to this page opens it (no 404).
3. The page shows the styled blocks, not plain unstyled text. If it looks plain, the HTML was pasted in Compose view instead of HTML view.
