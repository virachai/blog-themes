# 03-04 Page: เกี่ยวกับเรา

Create in Blogger → meefunblog → **Pages** → **New page**.

| Field | Enter |
| --- | --- |
| Title | `About Us (เกี่ยวกับเรา) - Mee Prompt (มีพร้อม)` |
| Permalink (Page settings → Permalink → Custom) | `about` → URL `https://meefunblog.blogspot.com/p/about.html` |
| Body | Switch the editor to **HTML view**, paste the whole of [02-meefunblog/09-page-about.html](../../02-meefunblog/09-page-about.html) |
| Search description (Page settings) | `Mee Prompt คือคลัง Prompt และ workflow AI ที่ทดสอบใช้งานจริง สำหรับเจ้าของธุรกิจและทีม SMB ไทย` |
| Comments (Page settings → Options) | Don't allow, hide existing |


## Check after publishing

1. Open `https://meefunblog.blogspot.com/p/about.html` on a phone and a desktop.
2. The menu or footer link to this page opens it (no 404).
3. The page shows the styled blocks, not plain unstyled text. If it looks plain, the HTML was pasted in Compose view instead of HTML view.
