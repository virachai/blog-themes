# 03-06 Page: ส่งพรอมต์

Create in Blogger → meefunblog → **Pages** → **New page**.

| Field | Enter |
| --- | --- |
| Title | `ส่งพรอมต์` |
| Permalink (Page settings → Permalink → Custom) | `form` → URL `https://meefunblog.blogspot.com/p/form.html` (the menu "ส่งพร้อม" and footer "Send Prompt" already link here) |
| Body | Switch the editor to **HTML view**, paste the whole of [02-meefunblog/12-page-form.html](../../02-meefunblog/12-page-form.html) |
| Search description (Page settings) | `ส่ง Prompt ที่ใช้ได้ผลจริงมาแบ่งปันกับ Mee Prompt` |
| Comments (Page settings → Options) | Don't allow, hide existing |

## Before publishing

Blogger cannot receive form submissions. Create a Google Form (fields: งานที่ใช้, Prompt, เครื่องมือ AI, ผลที่ได้, ชื่อสำหรับเครดิต, อีเมลติดต่อกลับ) and replace `[GOOGLE_FORM_URL]` with its share link.

## Check after publishing

1. Open `https://meefunblog.blogspot.com/p/form.html` on a phone and a desktop.
2. The menu item "ส่งพร้อม" opens this page.
3. The button opens the Google Form in a new page.
