# 03-02 Page: แท็กทั้งหมด

Create in Blogger → meefunblog → **Pages** → **New page**.

| Field | Enter |
| --- | --- |
| Title | `All Tags (แท็กทั้งหมด) - Mee Prompt (มีพร้อม)` |
| Permalink (Page settings → Permalink → Custom) | `tags` → URL `https://meefunblog.blogspot.com/p/tags.html` |
| Body | Switch the editor to **HTML view**, paste the whole of [02-meefunblog/07-page-tags.html](../../02-meefunblog/07-page-tags.html) |
| Search description (Page settings) | `แท็กของบทความ Mee Prompt สำหรับหาบทความตามเครื่องมือหรือประเภทงาน` |
| Comments (Page settings → Options) | Don't allow, hide existing |

## When labels grow

Add one `<a href="https://meefunblog.blogspot.com/search/label/LABEL" rel="tag">ชื่อที่แสดง</a>` line inside `mp-tag-list` per new label, in the repo file first, then paste again.

## Check after publishing

1. Open `https://meefunblog.blogspot.com/p/tags.html` on a phone and a desktop.
2. The menu or footer link to this page opens it (no 404).
3. The page shows the styled blocks, not plain unstyled text. If it looks plain, the HTML was pasted in Compose view instead of HTML view.
